FaceLogix ↗

Developer

A smart, secure attendance management system using AI-powered face recognition for automated tracking.

Computer vision · Python & PyTorch · Active

Project details

Combines face detection and feature extraction with vector similarity search for face matching. Liveness detection and spoof-resistant mechanisms help prevent unauthorized access through static images or video playback.

git clone https://github.com/LunarithmAI/FaceLogix.git

Developer

A high-fidelity Pomodoro timer combining minimalist design with advanced tracking, themes, embedded media, and AI-assisted task breakdown.

Vite & React · AI integration · Active
